# 落版單工具

編輯書冊時用的網頁版落版單。可以拖拉調整頁面順序、增減頁數，看到正確比例的跨頁、台的分界，以及裝訂內側要避開的範圍，最後輸出成 PDF 討論。

**開啟網址即可使用**：https://yijhenwang.github.io/imposition-sheet/

## 功能

- 依開本畫出正確比例的頁面，支援直式、橫式、正方形
- 左翻／右翻切換，版面跟著鏡像
- 顯示台的分界，提示頁數還差幾頁湊滿整台
- 跨頁中央顯示裝訂禁區，寬度隨裝訂方式改變
- 封面、封面裡、蝴蝶頁、封底裡、封底可選擇是否顯示（不計頁數）
- 章名頁自動編 Ch 號，順序調整後即時重算
- 頁面內容分兩層：第一層區塊（例如「推薦序」）、第二層內容備註
- 自動存檔、匯出／匯入落版檔（含版本號）、輸出 PDF

## 檔案

| 檔案 | 說明 |
| :--- | :--- |
| `index.html` | 可以直接打開使用的完整工具（由 `build.py` 產生，請勿直接編輯） |
| `src/template.html` | 原始碼 |
| `build.py` | 把起始資料塞進網頁，產生 `index.html` |
| `data/` | 起始資料：空白書冊與虛構範例 |

修改後執行 `python3 build.py` 重新產生 `index.html`。

## 資料存在哪裡

資料存在每個人自己的瀏覽器裡，不會上傳到任何地方，也不會互相看到。要把落版單交給別人繼續改，用「匯出落版檔」產生 `.json` 檔案傳給對方，對方再用「匯入落版檔」打開。
